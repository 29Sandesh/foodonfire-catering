## 🏛️ Project Architecture
This web application is a bespoke, production-ready digital banquet atelier built with:
- **Framework:** React 18 + TypeScript + Vite 5
- **Styling:** Tailwind CSS 3.4 + Custom Editorial Tokens
- **Routing:** React Router DOM v6
- **Icons:** Lucide React
- **Typography:** Google Fonts (`EB Garamond` & `DM Sans`)

---

## 💎 Features Built

### 1. **Atelier Home (`/`)**
- Asymmetric editorial split hero with signature dish spotlight.
- The 3 Pillars of Culinary Standards (Slow Hearth Dum Pukht, Pristine Spice Provenance, Silver-Glove Brigade).
- Foundational Banqueting Tiers Preview (Bronze, Silver, Gold).
- Signature Archival Masterworks Showcase.
- Dignitary testimonial and direct concierge appointment docket.

### 2. **The Heritage Codex & Philosophy (`/about-us`)**
- Archival narrative on 25+ years of Indore culinary lineage.
- The 4 Non-Negotiable Tenets (Time as an ingredient, hospital-grade hygiene, brass tablescape styling, patron discretion).
- Financial transparency and booking milestone charter (50% booking, 40% pre-event, 10% settlement).

### 3. **Digital Menu & Package Atelier (`/menu`)**
- Foundational package selector with immediate inclusion previews.
- Real-time multi-facet filtering:
  - **Category Tabs:** All Offerings, Canapés & Amuse, Royal Starters, Principal Mains, Imperial Biryanis, Live Counters, Dessert Atelier.
  - **Dietary Filter Pills:** All, Non-Veg (`NV`), Vegetarian (`VEG`), Vegan (`VEGAN`).
  - **Search:** Search across 60+ dishes by name, spice notes, or provenance.
- Direct interactive `+ Add To Selection` / portion adjustment steppers on every dish.

### 4. **My Selection & Order Planner (`/my-selection`)**
- Real-time shortlisted dishes itemization with portion multipliers and course balance meter.
- Interactive guest count slider (50 to 1,500+ connoisseurs).
- Service format selector (Artisanal Buffet, Silver Plated, Live Hearth).
- Financial ledger calculation showing package base and estimated grand total.
- **1-Click WhatsApp Concierge Order Dispatch:** Formats a complete, structured itemized proposal with client particulars and sends directly to `+91 9074284817`.
- **Formal Printable Proposal Dossier:** Modal view calibrated for browser printing and client PDF generation.

### 5. **Direct Concierge Directorate (`/contact-us`)**
- Atelier headquarters at Nyay Nagar & Radisson Square, Indore 452010 MP.
- Instant consultation booking form with dual online docket submit and WhatsApp dispatch.
